# Logo SISConforme, v2: minimalista (sem caixas d'água)

Uma nova rodada de prompts, com conceitos **abstratos e geométricos**. Nada de ilustração, nada de marco turístico. A logo precisa dizer só uma coisa: **três fontes que conferem**.

> A pasta `prompts-logo/` (v1, das três caixas d'água) continua lá como histórico. Esta aqui recomeça do zero.

## O que a logo precisa comunicar

Pela landing e pelo backend, o SISConforme é:

- **Cruzamento de 3 fontes**: cartão (credenciadoras), NFS-e e PGDAS
- **Conformidade**: quando os três números fecham, a empresa está "conforme"
- **Autorregularização**: a própria empresa corrige, antes da fiscalização
- **Institucional e sério**: serviço da Prefeitura (SEMEC), com sigilo fiscal

Ideia central para todas as variações: **3 → 1** (três coisas que se alinham ou se encontram e formam uma só).

## Regras de estilo (valem para todos os prompts)

- 1 cor, no máximo 2 (Ink + um acento)
- Formas geométricas puras: círculo, quadrado, linha reta
- Sem gradiente, sombra, 3D, textura, brilho, mascote ou cenário
- Precisa funcionar em **16 px** (favicon) e em uma cor só
- Nada de texto gerado por IA: o nome é montado depois no Figma

**Paleta** (a mesma da landing): Ink `#141413` · Ivory `#FAF9F5` · Clay `#D97757` · Green `#3C9A6B` (opcional, sugere "conforme")

**Base de estilo em inglês** (cole no fim de qualquer prompt):

```
Minimalist flat vector logo mark, pure geometric shapes, single color #141413 on plain #FAF9F5 background, no gradients, no shadows, no 3D, no texture, no text, no letters, centered, generous white space, Swiss modernist, Paul Rand / Pentagram style, works at 16px favicon size.
```

## Conceito 8: Só o nome (wordmark)

Sem símbolo nenhum: só a palavra, com um detalhe. **Não gere o texto na IA**, que erra letras. Use o prompt apenas para ver a ideia e monte o nome no Figma.

Ideias de detalhe:
- O pingo do **i** vira um quadradinho Clay
- O **o** de "Conf**o**rme" vira um círculo com check dentro
- "SIS" em peso 700 e "Conforme" em peso 400, sem espaço entre eles

```
Minimalist wordmark logo reading exactly "SISConforme", clean geometric sans-serif similar to Inter, "SIS" in bold and "Conforme" in regular weight, tight letter spacing, #141413 on plain #FAF9F5 background. The letter "o" in "Conforme" is replaced by a perfect circle containing a small checkmark in #D97757. Flat vector, no other elements, no gradients, no shadows.
```

(Para esse, use **Ideogram**, que é o gerador que melhor escreve texto.)

## Prompt de ajuste (use depois de escolher um conceito)

```
Simplify this logo further: remove any unnecessary detail, make all strokes the same weight, snap every shape to a strict geometric grid, increase white space, keep exactly one color plus at most one accent. Output as a flat vector on a plain background, no text.
```

## Negative prompt geral

```
text, letters, watermark, gradient, shadow, glow, 3d, bevel, texture, noise, photo, realistic, mascot, water tower, building, landscape, clipart, busy, ornate, multiple colors
```

## Checklist antes de aprovar

- [ ] Reconhecível em 16 × 16 px?
- [ ] Funciona só em preto? E em branco sobre `#141413`?
- [ ] Dá para descrever em uma frase ("três círculos com o centro laranja")?
- [ ] Não parece a logo de outro banco, fintech ou app de tarefas?
- [ ] Foi vetorizado (SVG), não é só o PNG da IA?

## Ferramentas

| Ferramenta | Para quê |
|---|---|
| **Recraft** (modo *Icon* / *Vector*) | Melhor para logo, já exporta SVG |
| **ChatGPT** | Segue bem prompts longos |
| **Midjourney** | Explorar muitas variações rápido |
| **Ideogram** | Só para o wordmark (conceito 8) |

**Sugestão:** comece pelos conceitos **1, 3 e 5**. São os que melhor contam a história de "três fontes que conferem" e os mais simples de vetorizar.
