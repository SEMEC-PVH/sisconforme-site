O mascote em movimento

Os 16 quadros da sua folha foram recortados, limpos e alinhados pelo chão. Aqui eles viram animações de verdade: parado, andando, pulando e comemorando. Use os botões ou o teclado.

Animação: parado · quadro 16

Teclado: ← → andar · Espaço pular · C comemorar

Como funciona

  1. A folha é uma grade. Cada quadro ocupa uma célula do mesmo tamanho (aqui 320 × 380 px), com o pé sempre na mesma linha do chão.
  2. Uma animação é uma lista de quadros. O pulo, por exemplo, usa os quadros 1 → 3 → 4 → 5 → 6 → 7 → 8 → 10 → 11.
  3. Um relógio troca o quadro. A cada 1/12 de segundo o código desenha o próximo quadro da lista, recortando a célula certa da folha.
  4. Movimento e estados. Andar é repetir o ciclo enquanto a posição muda; para a esquerda, a imagem é espelhada. Quando um pulo termina, o personagem volta a ficar parado.

O código essencial

const img = new Image(); img.src = 'sprites-normalizados.png';
const W = 320, H = 380, COLUNAS = 8;
const pular = [0, 2, 3, 4, 5, 6, 7, 9, 10];   // índices começam em 0
let i = 0;
setInterval(() => {
  const q = pular[i++ % pular.length];
  const sx = (q % COLUNAS) * W, sy = Math.floor(q / COLUNAS) * H;
  ctx.clearRect(0, 0, W, H);
  ctx.drawImage(img, sx, sy, W, H, 0, 0, W, H);   // recorta a célula e desenha
}, 1000 / 12);
